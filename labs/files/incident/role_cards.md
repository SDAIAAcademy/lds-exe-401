# بطاقات الأدوار في يوم المحاكاة

| الدور | يملك | لا يملك |
|---|---|---|
| الرئيس التنفيذي للمجموعة (قائد الحادثة) | القرار النهائي وسجل القرارات | التفاصيل التقنية |
| رئيس مكتب الذكاء الاصطناعي | مراجعة مخاطر الأداة وإيقافها المؤقت مع مالكها | قرارات التأديب |
| المدير العام للتوزيع (مالك العمل) | إيقاف الأداة مؤقتًا مع رئيس المكتب، والتواصل مع السائقين | الرد على الجهة المختصة |
| مسؤول حماية البيانات الشخصية | تقييم ما إذا كانت الحادثة تسربًا والإشعار | القرار التشغيلي |
| رئيس الأمن السيبراني | تحديد من وصلته القائمة واحتواؤها | تقييم الأثر القانوني |
| مدير الموارد البشرية | تعليق الإنذارات ومراجعتها وتصحيحها | تعديل الأداة |
| المستشار القانوني العام | صياغة الرد مع مسؤول حماية البيانات | القرار التشغيلي |
| المراقبون | تقييم القرارات والرد بسلم المحاكاة | التدخل |
