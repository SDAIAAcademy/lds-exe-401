# بطاقات أدوار لجنة المحفظة

| الدور | ما يسأل عنه |
|---|---|
| المدير المالي (رئيس اللجنة) | البند في الحسابات، والسقف، والتكلفة لكل نتيجة ناجحة |
| الرئيس التنفيذي للبيانات | جاهزية البيانات ومالكها وتصنيفها |
| رئيس المخاطر والالتزام | مستوى الخطر وقاعدة البيانات ومعيار الإيقاف |
| رئيس تقنية المعلومات | التشغيل والتكامل وتكلفة التشغيل |
| رئيس مكتب الذكاء الاصطناعي (أمين اللجنة) | يعرض الحالات ويكتب الورقة |
| مالكو الحالات | يعرض كل مالك حالته في ثلاث دقائق |
| المراقبون | يقيّمون الأسئلة والقرار بسلم المحاكاة |
