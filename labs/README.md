# مختبرات LDS-EXE-401: قيادة مكتب الذكاء الاصطناعي المؤسسي

عشرة مختبرات على حالة واحدة: **مجموعة الضُّمران**، مجموعة سعودية خاصة افتراضية بأربع شركات (التغليف، والتوزيع، وإدارة الأملاك، والمتاجر).
كل ما في الملفات اصطناعي: الأرقام والوحدات والأدوار، والأشخاص أدوار لا أسماء، وأرقام السائقين رموز لا أرقام وظيفية.
صنّفت المجموعة ملفات الحالة «عام» لأغراض البرنامج، فيجوز إدخالها في أي أداة ذكاء اصطناعي.

كل مختبر يبدأ من حالة مزوَّدة: من لم يُكمل المختبر السابق يبدأ من ملف في `files/*/fallback/`.
ولكل مختبر حل مرجعي في `solutions/`، ومفتاح للمدرّب في آخر صفحته.

## ما تحتاجه

- [`uv`](https://docs.astral.sh/uv/) وPython 3.11 أو أحدث. البرامج كلها ملفات مفردة بالمكتبة القياسية وحدها، تُشغَّل بـ `uv run` من جذر المستودع.
- جدول بيانات لتعبئة ملفات CSV، أو أي محرر نصوص.
- للمختبرين 1.1 و2.1 بنموذج حقيقي (اختياري): نموذج مستضاف مجاني بواجهة محادثة قياسية. انسخ `agent/.env.example` إلى `agent/.env` واملأ `LLM_BASE_URL` و`LLM_MODEL` و`LLM_API_KEY` من وثائق مزودك. لا يُرفع `.env` إلى المستودع. دون ذلك يعمل البرنامج بالبديل المكتوب بسيناريو.

## المختبرات وبرامجها

| المختبر | الملفات | البرنامج |
|---|---|---|
| 1.1 و2.1 وكيل الإرجاع | `files/agent/` | `uv run labs/agent/run_agent.py <workflow.json> --label run1` |
| 3.1 و4.1 خارطة الطريق | `files/roadmap/`، `files/case/` | `uv run labs/roadmap/roadmap_check.py <roadmap.csv> [--budget <budget.csv>]` |
| 5.1 لجنة المحفظة | `files/portfolio/` | `uv run labs/portfolio/portfolio_calc.py <decisions.csv> [--envelope 3782]` |
| 6.1 و7.1 و8.1 اختبار السياسة | `files/policy/` | `uv run labs/policy/matrix_check.py <matrix.csv>` |
| 9.1 و10.1 الحادثة | `files/incident/` | `uv run labs/incident/recount.py [--as-tool]` |

البرامج لا تقرر عن المشارك: تفحص وتحسب، والحكم في الحالة للمشارك.

## البديل المكتوب بسيناريو

دون مفاتيح نموذج، أو بالخيار `--stand-in`، يستعمل `run_agent.py` بديلًا من أسطر قليلة يقلّد أنماط فشل شائعة في الوكلاء
(التخمين عند الغموض، وتجاهل السياسة، والخطأ في الحساب، واتباع نص العميل). نتائجه تمرين تدريبي لتعلّم قراءة التشغيلين،
لا قياس لأي نموذج، والبرنامج يكتب ذلك في أول سطر من كل تشغيل. الأسعار في حساب التكلفة أسعار افتراضية للمقرر
(1.50 ريال لكل مليون رمز داخل و6.00 لكل مليون رمز خارج) لا أسعار أي مزود؛ وتُغيَّر بـ `PRICE_IN_SAR_PER_M` و`PRICE_OUT_SAR_PER_M`.

مخرجات التشغيل في `agent/runs/<label>/`: `trace.jsonl` (حدث بصيغة JSON في كل سطر، يعرضه الخيار `--view`؛ وإرساله إلى عارض آثار مثل Langfuse أو Arize Phoenix يحتاج إلى مكتبة العارض)، و`results.csv`، و`summary.json`.
المجلد لا يُرفع إلى المستودع.

## للمدرّب

- `uv run labs/solutions/check.py all` يعيد حساب كل الأرقام المرجعية من ملفات الحالة ويشغّل البرامج على الحلول المرجعية، ويطبع PASS لكل مختبر.
- `uv run labs/_tools/prepare_files.py` يعيد كتابة ملفات الحالة والحلول المرجعية بالبايتات نفسها (بذرة ثابتة).
- مدخلات يومي المحاكاة في `solutions/portfolio/injects_w5.md` و`solutions/incident/injects_w10.md`: لا توزَّع قبل وقتها.
- سلالم النضج وصلاحيات الوكلاء وخطورة الحادثة أدوات المقرر لا معايير وطنية؛ ومصفوفة مستوى الخطر من الإطار الوطني لإدارة مخاطر الذكاء الاصطناعي.
